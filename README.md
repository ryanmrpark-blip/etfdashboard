# 📊 네이버 증권 ETF 실시간 종합 EDA 대시보드

네이버 증권 국내 ETF API를 활용하여 국내 상장된 전체 ETF 종목(1,070여 개)의 실시간 데이터를 수집하고, 다차원 탐색적 데이터 분석(EDA, Exploratory Data Analysis)을 제공하는 고성능 정적 웹 대시보드입니다.

GitHub Pages, Cloudflare Pages, Vercel, Netlify 등 **정적 웹 호스팅 환경에 즉시 배포**할 수 있도록 설계되었습니다.

---

## 🌟 주요 기능 및 EDA 분석 모듈

### 1. 📈 핵심 시장 지표 (Executive Summary KPIs)
- **전체 순자산(AUM)** 및 상장 종목 수
- **당일 총 거래대금** 및 시장 일평균 자산 회전율(Turnover Rate)
- **시장 심리 지표(Market Breadth)**: 상승 종목 수 vs 보합 종목 수 vs 하락 종목 수 실시간 비율
- **AUM 가중평균 등락률** 및 단순평균 등락률 비교
- **시장 집중도(Market Concentration)**: 상위 3개 운용사 점유율(CR3) 및 허핀달-허쉬만 지수(HHI) 산출
- **괴리율 위험 경보**: 순자산가치(iNav) 대비 괴리율 절대값 1.0% 이상 고위험 종목 자동 집계

### 2. 🏢 운용사(브랜드) & 자산군 구조 분석
- **운용사별 AUM 점유율 도넛 차트**: KODEX(삼성), TIGER(미래에셋), ACE(한국투자), RISE(KB), SOL(신한), PLUS(한화) 등 주요 브랜드별 점유율 및 종목 수 분석
- **자산군별 순자산 규모 가로 막대 차트**: 국내주식, 해외주식, 국내채권, 해외채권, 원자재/상품, 자산배분/혼합, 파생/레버리지 등
- **자산군별 기간별(1M / 3M / 6M) 평균 수익률 비교**: 자산 분류별 중단기 성과 모멘텀 추세 비교

### 3. 🎯 수익률 분포 & 모멘텀 분석
- **기간별 수익률 도수분포 히스토그램**: 1개월 / 3개월 / 6개월 수익률 분포 인터랙티브 토글
- **수익률 랭킹**: 1개월 최고 수익률 TOP 10 및 최저 수익률 하위 10 실시간 순위

### 4. 💧 유동성 & 회전율(Turnover) 분석
- **순자산(AUM) vs 거래대금 상관 산점도(Scatter Plot)**: 로그 스케일 기반 유동성 이상치 및 자산 규모 대비 거래 활발도 종목 탐색
- **자산 회전율 상위 TOP 10**: 순자산 100억 이상 종목 중 당일 손바뀜이 가장 활발한 ETF 발굴

### 5. 🛡️ 괴리율 & 추적 오차 위험 분석
- **시장가 vs iNav 괴리율 구간 도수분포**: 정상 범위(-0.5% ~ +0.5%) 및 고평가/저평가 구간
- **괴리율 고평가 TOP 8**: 실제 가치 대비 시장 가격이 지나치게 높게 형성된 투자 유의 종목 실시간 경보

### 6. 🔍 인터랙티브 전체 종목 탐색기 (Data Explorer)
- **다중 실시간 필터**: 종목명/종목코드 검색, 운용사/브랜드 필터, 자산분류 필터, 상승/하락 필터, 괴리율 주의 종목 필터
- **테이블 헤더 정렬**: 현재가, 등락률, 거래대금, 순자산, 1M/3M/6M 수익률, 괴리율 등 모든 컬럼 오름차순/내림차순 정렬
- **종목 상세 팝업 모달**: 클릭 시 네이버 증권 바로가기 및 상세 지표(iNav, 회전율, 세부 유형 등) 확인
- **데이터 내보내기**: 필터링된 데이터를 **CSV** 또는 **JSON** 파일로 즉시 다운로드

## 🚀 3단계 하이브리드 데이터 수집 전략

정적 페이지 배포 환경에서도 실시간 데이터를 끊김 없이 안정적으로 서비스하기 위해 3단계 캐스케이드 데이터 파이프라인을 지원합니다:

1. **1순위 (초고속 첫 화면 로드)**: 번들된 최신 정적 데이터 `data/etf_data.json`을 즉시 로드하여 0.1초 만에 대시보드 렌더링
2. **2순위 (실시간 브라우저 동기화)**: 상단 **[실시간 동기화]** 버튼 클릭 시 네이버 주식 API (`size=100`, `index=1..N`)를 호출하며, 브라우저 CORS 제한 시 CORS 프록시를 통해 자동 우회 수집
3. **3순위 (로컬/CI 최신 수집 스크립트)**: `uv run python fetch_data.py`를 통해 언제든 전체 1,070여 개 종목을 1~2초 만에 최신 JSON으로 갱신 가능

## 💻 실행 및 배포 방법

### 1. 로컬에서 실행하기

별도의 복잡한 빌드 과정 없이 `index.html` 파일을 브라우저로 열거나, 로컬 웹서버를 실행합니다:

```bash
# 로컬 웹 서버 실행 (Python uv 사용)
uv run python -m http.server 8080
```
브라우저에서 `http://localhost:8080`으로 접속합니다.

### 2. 최신 데이터 갱신하기 (Python uv)

```bash
uv run python fetch_data.py
```
`data/etf_data.json` 파일에 최신 데이터가 즉시 저장됩니다.

### 3. 정적 호스팅 (GitHub Pages) 배포

1. 이 저장소의 모든 파일(`index.html`, `css/`, `js/`, `data/`, `README.md`)을 GitHub 저장소에 푸시합니다.
2. GitHub 저장소의 **Settings** > **Pages**로 이동합니다.
3. **Branch**를 `main` (또는 `master`) / `/(root)`로 선택하고 **Save**를 누릅니다.
4. 배포된 URL(`https://<username>.github.io/<repo-name>/`)로 즉시 전 세계 어디서든 대시보드를 사용할 수 있습니다.

## 📁 디렉터리 구조

```text
├── index.html           # 메인 대시보드 정적 페이지
├── css/
│   └── styles.css       # 모던 핀테크 스타일 디자인 시스템 (다크/라이트 테마)
├── js/
│   ├── api.js           # 3단계 하이브리드 데이터 페치 엔진 (실시간/프록시/로컬)
│   ├── eda.js           # 통계 집계, HHI 집중도, 괴리율 계산, EDA 분석 엔진
│   ├── charts.js        # Chart.js 시각화 모듈 (도넛, 막대, 산점도, 히스토그램)
│   └── app.js           # 상태 관리, 테이블 정렬/필터, 페이지네이션, 모달, 내보내기
├── data/
│   └── etf_data.json    # 국내 전체 상장 ETF 초기 번들 데이터
├── fetch_data.py        # Python uv 기반 전체 종목 수집 CLI 스크립트
└── README.md            # 프로젝트 안내 및 가이드
```

## 🎨 기술 스택 & 라이브러리
- **HTML5 & Vanilla CSS**: TailwindCSS 등의 빌드 의존성 없이 순수 모던 CSS로 구현된 커스텀 반응형 UI & 글래스모피즘
- **Vanilla JavaScript (ES6+)**: 빌드 도구 없는 네이티브 모듈형 구조
- **Chart.js (v4.4.4)**: 고품질 인터랙티브 캔버스 차트 시각화
- **Lucide Icons**: 모던 벡터 아이콘
- **Pretendard Font**: 금융 데이터 및 한글 가독성 최적화 웹폰트
